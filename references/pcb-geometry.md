# PCB 几何

## 一、单位

PCB 侧坐标单位是 **mil**，与 `CANVAS.unit` 写的 `mm` 无关（该字段是显示设置）。
1 mil = 0.0254 mm。

直接把 mil 当 mm 会把板子算小 39 倍。`pcbnet.MIL_TO_MM` 统一换算，
产物里同时给 `*_mil` 和 `*_mm`，报告只打印 mm。

## 二、走线

`LINE`（PCB 文档内）字段：

| 字段 | 含义 |
|---|---|
| `startX/startY/endX/endY` | 端点，mil |
| `width` | 线宽，mil |
| `layerId` | 所在层 |
| `netName` | 网络名 |

长度 = 各段欧氏距离之和。按网络聚合后可以看总长、段数、线宽众数。

`width` 常出现 `7.874` / `15.748` 这类值，是 0.2 mm / 0.4 mm 的 mil 表示，
不是"奇怪的线宽"。

## 三、过孔

`VIA` 字段：`netName` `centerX/Y` `holeDiameter` `viaDiameter` `viaType`
`unusedInnerLayers`。

孔径直方图能直接看出用的是哪种孔（常见 0.3 mm = 11.811 mil）。

两条限制：

- 铺铜缝合孔两端没有走线，把它插进链路会造悬空节点；统计数量可以，参与电气拓扑不行；
- 过孔不能合并节点。换层后 via 的 R/L 无处安放，必须"每层一个节点 + 串联元件"。

## 四、焊盘与封装

封装焊盘在 `FOOTPRINT` 文档的 `PAD` 记录里，坐标是封装本地坐标：

```
焊盘绝对坐标 = COMPONENT.x/y + rot(COMPONENT.angle) · (PAD.centerX/centerY)
```

焊盘号（`PAD.num`）是物理引脚号的唯一可靠来源。标准 SOP/SSOP/QFN 为 1 脚左上、
逆时针；有疑问时用焊盘坐标反推方向，再和丝印的极性标记对照。

## 五、板框

`POLY` 记录，`polyType == "BOARD_OUTLINE"`（层 id 通常为 11）。
`path` 有两种写法：

```json
["R", x, y, w, h, rot, radius]      // 角点 + 带符号宽高
[[x1,y1],[x2,y2], ...]              // 点序列
```

`R` 形式的 `w`/`h` 可能为负（表示向左/向下画），取包围盒即可，
不要直接相加。**末尾的 `rot` / `radius` 不是坐标点**——当成点算的话，
任何不落在原点的矩形都会多出一个 `(rot, radius)` 点，包围盒被撑到原点，
板框尺寸能差出一个数量级（`_poly_points()` 已跳过这两位）。

## 六、层与叠层

`LAYER` 表**恒有 60+ 条**：两层板也会列 `INNER1..INNER30`。
判据只有一个——**被走线或焊盘真正引用的才是真实层**。

`LAYER_PHYS` 存叠层物理参数，但只有介质层通常有真实数据
（`thickness` / `er` / `lossTangent`），铜层的 `thickness` 常为 0 或 `null`。

因此：

- 不要因为"没读到铜厚"就默认 1oz；
- 不要因为"没读到 er"就默认 FR4 = 4.5；
- 数据不全时明确输出"叠层不完整"，让用户补。

按层数推导检查项，不要套样板：

| 层数 | 该查什么 |
|---|---|
| 2 层 | 顶层/底层走线、通孔；**不要**因为"没有内层平面"报缺陷 |
| 4 层+ | 内层平面完整性、是否被分割、有无跨分割走线、参考平面连续性 |
| 盲埋孔/HDI | 孔类型与叠层是否匹配、孔环、激光孔焊盘 |

## 七、铺铜与禁布区

- `POUR`（定义）与 `POURED`（填充多边形）：判断某个区域是否真的铺了铜；
- `REGION`（禁布区，`prohibitType`）：判断设计要求挖空的地方是否真的挖空。

铺铜重灌会让 `POURED` 多边形整体变化，做版本 diff 时必须整类过滤，否则满屏噪声。

## 八、丝印

`STRING` / `TEXT` 记录的 `layerId`（3 = 顶层丝印，4 = 底层丝印）与坐标。

按坐标把每段文字归到最近的 `COMPONENT`（`sqrt(dx²+dy²)` 最小），再和 BOM 值比对。
**必须按坐标归属，不能按文字内容猜**：旧标注串会被保留，同一元件可能有多段文字，
只看内容会误判"丝印没改"。

## 九、几何检查的常见真缺陷

| 现象 | 判定 |
|---|---|
| 丝印标称值 ≠ BOM 值 | 装配错件风险，P1 |
| 丝印层与元件层不一致 | 排针在上层、标签打在底层 = 错层，P2 |
| 设计要求挖空但整板铺铜 | P1 |
| 无安装孔 / 孔径单一 | 装配风险，P2 |
| 极性标记缺失 | 电解电容、二极管、连接器，P1 |
| 测试点缺失或间距不足 | 可制造性/可维修性，P2 |
